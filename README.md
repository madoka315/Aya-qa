# Aya问答

HoshinoBot 使用的群问答插件。基于 [eqa](https://github.com/pcrbot/erinilis-modules/tree/master/eqa) 项目改造，更符合日常使用习惯。

## 安装依赖

在运行 HoshinoBot 的 Python 环境中执行：

```bash
pip install -r requirements.txt
```

`Pillow<10` 用于长列表图片展示，并兼容 Python 3.8；未安装 Pillow 时，长列表会回退为文字。

## 常用指令

### 设置问答

```text
大家说 早上好 回答 早上好！
我说 今天吃什么 回答 看你想吃什么
```

- `大家说` / `有人说`：设置全群问答。
- `我说`：设置个人问答，只有设置者本人触发时才会回复。
- `回答` 可以带文字、图片或 @。
- 一句话设置多个关键词：

```text
我说 哈喽|你好|在嘛 回答 在呢～
```

多个关键词中的任意一个都可以触发同一个回答。关键词按字面匹配。

### 正则问答

在问题前加 `R`，并且后面确实包含正则符号：

```text
我说 R测试\d+ 回答 这是数字测试
```

普通的 `RPG`、`R星游戏` 不会被误判为正则，`R` 会保留为问题内容。

### 查看问答

```text
问答                    查看自己设置的问答
问答@某人               查看某人设置的问答
全部问答                查看本群全部问答
全部问答 关键词         搜索包含关键词的问答
```

“全部问答”会分成“全群问答”和“个人专属问答”两区；带 `*` 的词同时出现在两个区。列表较长时会自动整理成一张图片，短列表仍直接发送文字。

### 删除问答

```text
不要回答 早上好         删除一个问答
清空回答 早上好         清空这个问题的全部回答（仅超级管理员）
```

删除时不需要记住正则问答是否带 `R`，插件会自动尝试普通问题、正则问题和多关键词问题。

## 图片说明

问题或回答可以包含图片。图片会先缓存到本地后再发送，单张图片最大 8 MB；下载失败、非图片内容或超过大小限制时不会保存。

## 配置说明

配置文件为插件目录下的 `config.yaml`。修改配置后需要重启 HoshinoBot。

### 管理员与缓存

- `admins`：插件管理员 QQ 号列表。这里的管理员与 HoshinoBot 配置的超级用户都会被视为超级管理员。
- `cache_dir`：问答数据库和图片缓存目录；默认 `./data/`，相对于插件目录。
- `image_base64`：是否将缓存图片以 Base64 形式保存和发送。通常保持 `false`；只有部署环境明确需要 Base64 图片时再开启。

### `comm`：指令文字

可以按需修改指令关键词；修改后，群里需要使用对应的新文字。

- `answer_all`：设置全群问答的开头，可配置一个或多个词，例如 `大家说`、`有人说`。
- `answer_me`：设置个人问答的开头，默认 `我说`。
- `answer_handler`：问题和回答之间的分隔词，默认 `回答`。
- `answer_delete`：删除单条问答的开头，默认 `不要回答`。
- `answer_delete_all`：清空某问题全部回答的开头，默认 `清空回答`。
- `show_question`：查看个人问答的开头，默认 `问答`；后接 @ 可查看指定成员。
- `show_question_list`：查看本群问答列表的指令，可配置一个或多个词，默认 `全部问答`、`所有问答`；后接关键词可搜索。

### `rule`：权限和问答行为

- `only_admin_answer_all`：是否仅允许群管理员和超级管理员设置全群问答；默认 `true`。
- `super_admin_is_all_group`：超级管理员设置的全群问答是否在所有群生效；默认 `true`。
- `only_admin_can_delete`：是否只允许管理员删除其他人的问答；默认 `true`。
- `can_delete_super_admin_qa`：群管理员是否可以删除超级管理员设置的问答；当前为 `true`。
- `question_del_last`：删除时优先删最近设置的回答；默认 `true`。
- `multiple_question_random_answer`：同一问题有多个回答时是否随机选择；默认 `true`。
- `priority_self_answer`：是否优先使用触发者自己设置的回答；默认 `true`。
- `member_can_show_other`：普通群员是否可以查看其他成员设置的问题；默认 `true`。
- `use_cq_code_image_url`：是否允许设置以 `?` 开头的自定义图片 URL；默认 `true`。只应使用可信来源的图片链接。

### `str`：显示和特殊前缀

- `reg_match_cmd`：正则问答前缀，默认 `R`。
- `cmd_head_str`：原版预留的命令回答前缀。当前 aiocqhttp 实现不会执行该功能，不建议依赖。
- `print_all_split`：问答列表文字模式下的问题分隔符，默认 ` | `。

长列表图片显示也有少量代码级选项，位于 `util.py`：`LIST_RENDER_AS_IMAGE` 控制是否启用、`LIST_IMAGE_MAX_CHARS` 控制转图片的字符阈值、`LIST_IMAGE_WIDTH` 控制图片宽度；改动后同样需要重启。

## 与原版 eqa 的差异

主要差异如下：

- 服务名由 `eqa` 改为 `问答`，权限默认配置为“全群问答仅管理员可设置”。
- 修复个人问答随机选中后导致无回复的问题。
- 修复自定义图片 URL 被错误改写成本地路径的问题。
- 修复 @成员取名失败时的列表错位，以及“回答”被拆成多个消息段时的错误切片。
- 图片下载改为不阻塞主事件循环，增加 HTTP 状态检查、异常处理、流式下载和 8 MB 大小限制。
- 使用文件魔数识别 JPEG、PNG、GIF、WebP、BMP、TIFF，减少错误的 `.None` 缓存文件。
- 超长问题只在展示时截断，不修改原始问答内容。
- 支持 `A|B|C` 多关键词问答，并正确处理 `C++`、`C#` 等特殊字符。
- 改进 `R` 正则前缀判断；删除时自动识别普通、正则和多关键词问答。
- “全部问答”增加分区、重复标记、关键词搜索和长列表图片展示；临时列表图片只保留最近 20 张。


## 安全提示

正则问答会在群消息中进行匹配。当前实现没有正则匹配超时限制，因此复杂或恶意构造的正则可能拖慢消息处理。请只在可信群内开放问答设置权限，并谨慎使用正则；如需面向不可信群开放，建议先增加正则权限限制或安全匹配方案。

## 维护提示

修改代码或配置后需要重启 HoshinoBot 才会加载新逻辑；问答数据库本身是实时读写的。
